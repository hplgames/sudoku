# Sudoku Gia Đình

Sudoku cho cả nhà, chơi ngay trên trình duyệt máy tính hoặc điện thoại.

- Bàn 4×4 (cho bé, có thể dùng hình 🍎🐶⭐🐟 thay số), 6×6 và 9×9
- 3 mức Dễ / Vừa / Khó, đề tự tạo, luôn có đúng một lời giải
- Hướng dẫn cách chơi bằng hình động, 6 bước
- Gợi ý có giải thích: tô sáng hàng, cột, khối cho biết vì sao ô đó là số đó
- Ghi chú bút chì, đi lại, báo lỗi ngay, đồng hồ
- Pháo hoa và nhạc mừng khi giải xong
- Tiếng Việt / English / 中文

Toàn bộ game nằm trong một file `index.html`, không cần cài đặt.
